
# JesterAI

> 🤖 Бот для развлечения, управления стикерами и отслеживания активности пользователей.

---

## 🎯 Описание бота

Этот бот предназначен для:
- Управления стикер-паками (создание, редактирование, просмотр)
- Ведения статистики и отображения лидеров
- Проведения интерактивных игр (например, "Гамба!")
- Предоставления информации о пользователе и его действиях
- Управления запланированными задачами и командами

Бот — это не просто помощник, а среда для творчества, развлечений и взаимодействия!

---

## 🤖 Команды бота

Бот поддерживает следующие команды:

### 📌 Основные
- `/start` — начать сессию
- `/help` — показать список команд

### 🎨 Стикеры
- `/create_sticker_set` — создать новый стикер-пак
- `/edit_sticker_set` — изменить стикер в паке
- `/sticker_pack` — ссылка на актуальный набор стикеров бота

### 👤 Пользователь
- `/me` — информация о пользователе
- `/pencil` — интерактивное действие с текущим размером пользователя

### 📊 Игры и статистика
- `/leaderboard` — таблица лидеров
- `/trash_loto` — игра "Гамба!", для развлечения

### 📅 Запланированные задачи
- `/jobs` — список активных запланированных команд

> 💡 *Некоторые команды могут требовать дополнительных прав или быть доступны только в определённых чатах.*
